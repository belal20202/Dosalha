# دوسلها — v1.7.0
لعبة سباق بسيارات كلاسيكية على طرق ومرتفعات: 100 مرحلة في 10 مدن، 60 سيارة، تطوير للسيارات، موسيقى وأصوات، حفظ تلقائي للتقدم.

## بناء ملف APK من GitHub
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub (الفرع main) مع الحفاظ على المجلدات.
2. تبويب **Actions** ← **Build APK** ← انتظر الاكتمال.
3. نزّل **dosalha-apk** من Artifacts — بداخله `app-debug.apk` (أفقي + ملء الشاشة).

## ملاحظات
- الأيقونة: مجلد `resources/android` (تُنسخ تلقائياً عند البناء) و`store-icon-512.png` لأيقونة المتجر.
- سياسة الخصوصية: `www/privacy-policy.html` — غيّر البريد فيها، وتوجد أيضاً داخل اللعبة في الإعدادات.
- التحكم: النصف الأيمن بنزين، الأيسر فرامل/توازن في الهواء. كمبيوتر: الأسهم أو A/D، و P للإيقاف.
